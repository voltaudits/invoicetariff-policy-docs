# 美国进口关税是怎么算的

> 信息截至 **2026-09-16**。关税政策时效性强，最新变化请见 [关税雷达（变更日志 + 邮件提醒）](https://invoicetariff.com/zh/radar)。
> Other language: [English](../en/01-us-tariff-calculation.md)

## 一句话公式

美国进口关税的每一层都是**同一个完税价格**上的从价百分比，各层**相加**，不叠加复利：

```text
总关税   = 完税价格 × (MFN 税率 + 301 税率 + 232 税率 + …)
规费     = MPF（货值的 0.3464%，每票最低 $33.58 / 最高 $651.50）
         + HMF（货值的 0.125%，仅海运）
应缴 CBP = 总关税 + 规费
```

三条推论：

- **税率相加，不相乘。** 16.5% + 7.5% + 12.5% = 36.5%，而不是 1.165 × 1.075 × 1.125 ≈ 40.9%。
- **国际运费不计入完税价格。** 与欧盟、加拿大按 CIF 估价不同，美国采用成交价格，国际运费与保险单独列明时予以剔除。
- **规费不是关税。** MPF（商品处理费）与 HMF（港口维护费）属于另一法源的用户规费，按票计收，不随贸易项目的退税退还。

## 完税价格是什么

美国完税价格是 19 U.S.C. § 1401a 定义的**成交价格**（transaction value）：出口至美国销售时实际支付或应付的价格，再加上若干未包含在货价内的加项：

| 计入完税价格 | 不计入（须单独列明） |
|---|---|
| 支付卖方的货款 | 国际运费与保险 |
| 包装费 | 进口后的美国境内运费 |
| 买方支付的销售佣金 | 关税与规费本身 |
| **协助（assists）**——买方免费或低价提供的模具、工具、材料、设计 | 买方佣金 |
| 作为销售条件买方必须支付的特许权使用费 | 进口后服务（安装、培训） |
| 归卖方所有的转售收益 | |

实务中，多数电商与批发货物的完税价格就是 **FOB / EXW 发票货值**。即使你按 DDP 报价，申报的仍是货物本身的价值——关税是你的成本，不该申进价格里。

## 一票货可能踩中的关税层级

| 层级 | 法律依据 | 适用范围 | 税率如何确定 |
|---|---|---|---|
| **MFN 基础税率**（HTSUS 第 1 栏 "General"） | 1930 年关税法；HTSUS 第 1 栏 | 所有正常贸易关系国家 | USITC 按 8/10 位 HTS 编码固定："Free"、百分比或从量/复合税率 |
| **对华 301**（清单 1–4A 及四年复审加征） | 1974 年贸易法 §301（USTR） | 仅中国原产货物 | 清单 1–3 为 25%，清单 4A 为 7.5%；复审产品更高（如光伏电池 50%） |
| **全球 301 计划** | 1974 年贸易法 §301（USTR，2026-07-24 生效） | 按经济体分层——中国 12.5%、英国 10% 等，部分伙伴设合并上限 | 按经济体载于 FR 2026-15181；产品排除另行公布 |
| **232 条款** | 1962 年贸易扩展法 §232（总统公告） | 特定产品行业、不分原产国：钢铝 50%、铜 50%、汽车及零部件 25%、木材 10%、家具 25%、半导体 25%、药品（2026-09-29 起分层） | 按各公告附件所列 HTS 范围；部分衍生品仅按金属含量计 |
| **338 条款** | 1930 年关税法 §338（19 U.S.C. §1338，总统公告） | 对美贸易存在歧视的国家的货物——目前为加拿大机动车、乳制品与酒精饮料（50%，2026-08-22 起） | 公告最高 50%；与其他层级叠加，但已属 232 范围的货物不适用 |
| **AD/CVD（反倾销/反补贴）** | 1930 年关税法第七编（Commerce / ITC） | 特定案件点名的生产商或国家 | 案件个定，税率常极高；进口时按保证金预缴、事后清算 |
| **MPF + HMF** | 19 U.S.C. §58c（MPF）；26 U.S.C. §4461（HMF） | 每票正式报关（HMF 仅海运） | MPF 为货值 0.3464%，设每票上下限；HMF 为货值 0.125% |

两个仍被时常提及、但已**不适用于新报关**的项目：

- **IEEPA「对等关税」与芬太尼关税**（Chapter 99 税号 9903.01 / 9903.02）：2026-02-24 被最高法院裁定违法后终止；2025-02-04 至 2026-02-24 期间缴纳的税款可经 CBP CAPE 流程申请退还——见 [IEEPA 退税详解](03-ieepa-tariffs-and-refunds.md)。
- **De Minimis 800 美元免税额度**：自 2025-08-29 起对所有国家暂停，低值包裹按同一套关税栈计税——见 [De Minimis 详解](02-de-minimis-suspension.md)。

## 从量税与复合税

并非所有 MFN 税率都是百分比。HTSUS 还使用：

- **从量税率**——按单位数量计固定金额，如大米 *2.1¢/kg*。需要申报净重（或数量），而不只是货值。
- **复合税率**——百分比 + 从量部分，如钢制螺栓 *9% + 0.5¢/kg*。

即使 MFN 基础税率为从量/复合，301、232 层级仍按完税价格从价计征。计算器会显示从价层级，并在涉及从量税时要求填写净重；缺净重时结果会标注为部分估算。

## 算例：中国产棉质 T 恤

以 HTS **6109.10.00**（针织棉制 T 恤）、货值 $10,000、海运正式报关、1,000 件为例：MFN 税率、对华 301 税率与全球 301 层级各自乘以同一个 $10,000 后相加；MPF 与 HMF 也按同一个 $10,000 计收（不是按「货值 + 关税」）。总价除以件数，就是你要摊进落地成本的单件关税。

换掉任何一个输入——原产国、HTS 编码、报关日期、海运还是空运——关税栈都会变。所以「中国关税是多少」从来没有单一答案：它是**特定编码在特定日期触发的各层级之和**。

## 法定税率 ≠ 实际税率

- **法定税率**：单个项目自己的税率，如「301 项下 25%」。
- **实际税率（effective rate）**：(全部关税 + 规费) ÷ 完税价格。

上例的实际税率约 37%，尽管没有任何单一项目收 37%。比较不同国家供应商、决定涨价传导时，应该用实际税率。

## 哪些变量会改变结果

- **报关日期**。税率与时间绑定：全球 301 自 2026-07-24 生效；MPF 上下限 2026-10-01 随 FY2027 调整；232 药品关税 2026-09-29 启动。引擎按生效窗口取数，[关税雷达](https://invoicetariff.com/zh/radar)逐条记录每次变化及其 Federal Register 来源。
- **原产国**——货物在哪儿制造或发生最后实质性改变，而非从哪儿发运。经第三国转口不改变原产地。
- **报关类型**。正式报关按从价缴 MPF；邮政非正式报关（≤ $2,500）缴固定规费。HMF 只对海运货物征收。
- **AD/CVD** 案件按「产品 × 国家」叠加在一切之上。
- **优惠贸易安排**（如 USMCA）可把 MFN 层降为零，但一般不能豁免 232 或 301 层级。

## 动手查你自己的关税栈

1. **先定准编码**：从 [HTS 编码查询](https://invoicetariff.com/zh/hts)出发，对照 USITC 或海关裁定确认 8/10 位编码。
2. **查编码页**：每个编码页（如 [/zh/hts/61091000](https://invoicetariff.com/zh/hts/61091000)）列出该编码适用的全部层级（MFN、对华 301、全球 301、232）及其税率、生效窗口、核实状态与 Federal Register 来源。
3. **跑一遍计算**：[美国关税计算器](https://invoicetariff.com/zh)按指定日期、原产国与运输方式计算整条关税栈。
4. **整表批量**：SKU 多于几条时，用 [SKU 批量测算](https://invoicetariff.com/zh/batch)上传 XLSX/CSV 一次算完，结果自带规则集版本号。
