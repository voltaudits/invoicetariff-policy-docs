## 编辑约定

- 每篇文章标注**「信息截至」日期**。关税政策时效性强；凡涉及税率与日期，均给出对应的**《联邦公报》（Federal Register）文号**。实时变更请看[关税雷达](https://invoicetariff.com/zh/radar)。
- 中英版本**一一对应**——结构相同、数字相同，每个文件互设对方语言的跳转链接。
- 税率与日期与 [invoicetariff.com](https://invoicetariff.com) 计算引擎所用的规则集保持一致；站内每一条税率都链接到其来源公告。

## 免责声明

本文库内容为一般性政策解读，仅供参考，**不构成**报关、法律或税务意见。实际申报应以 HTSUS 税则、Federal Register 公告与 CBP 指引为准，或向贵司的持证报关行确认。
